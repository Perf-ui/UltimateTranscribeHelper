# Windows x64 plugin

The Windows DLL is built from NNLS Chroma commit
`4c5f214a75cb354f8d8c933e161377c5b4d83713` and Vamp Plugin SDK commit
`63e0c3b37b6fb9ce6f074ea8222b4903e4f5568a` using MSVC 14.44 and Boost 1.85.
The source is available at https://github.com/c4dm/nnls-chroma and
https://github.com/c4dm/vamp-plugin-sdk; the build command is in
`scripts/windows/build_chroma.cmd` in the Omnizart source tree. The plugin is
GPL version 2 or later; see COPYING.
